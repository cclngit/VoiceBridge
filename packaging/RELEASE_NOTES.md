## Download

| System | File |
| --- | --- |
| Windows (x64) | `VoiceBridge-windows-x86_64-setup-*.exe` |
| Windows (ARM64) | `VoiceBridge-windows-arm64-setup-*.exe` |
| macOS (Apple Silicon & Intel) | `VoiceBridge-macos-universal-*.dmg` |
| Linux (Debian / Ubuntu) | `VoiceBridge-linux-amd64-*.deb` / `VoiceBridge-linux-arm64-*.deb` |

The Windows x64 installer includes everything needed for GPU acceleration: CUDA on NVIDIA cards and Vulkan on AMD / Intel, with a CPU fallback. Nothing else to install.

Already installed? VoiceBridge offers the update itself.
